La Compañía del Código

Ocho agentes de IA, una sola hermandad. Le confiás una tarea en lenguaje natural y la llevan desde la idea hasta un Pull Request revisado, testeado y seguro — listo para mergear.

¿Qué es este equipo?

Es un equipo de agentes de IA construido con LangGraph y la API de Claude (Anthropic). Le das una tarea en lenguaje natural —"creá un módulo que haga X"— y la Compañía atraviesa el ciclo completo de desarrollo por vos, sin que tengas que orquestar cada paso a mano.

Cada agente es un especialista con su propio rol y su propio modelo de Claude. Trabajan sobre un estado compartido y, lo más importante, forman un bucle de mejora: el código se reescribe una y otra vez hasta pasar revisión de calidad y auditoría de seguridad, antes de avanzar.

El resultado de una sola corrida: código + tests ejecutados + documentación + análisis de dependencias + descripción de PR y CHANGELOG.

¿Para qué sirve? — Aplicaciones

Dónde esta Compañía te ahorra horas de trabajo en proyectos reales.

🧩

Prototipado rápido de módulos

Convertí una idea en un módulo Python tipado, testeado y documentado en una sola corrida. Ideal para utilidades, parsers, clientes de API o helpers autocontenidos.

🛡️

Código con seguridad incorporada

Cada entrega pasa por un auditor que combina razonamiento de Claude con bandit (SAST real): detecta inyección, secrets hardcodeados y riesgos OWASP antes de que lleguen al repo.

🧪

Tests generados y ejecutados de verdad

No solo escribe tests: los corre con pytest en un sandbox y te devuelve el resultado real. Sabés si el código funciona, no solo si "parece" funcionar.

📚

Enseñar arquitectura multi-agente

Un caso de estudio vivo de patrones de coordinación: grafo, bucles condicionales, fan-out paralelo y asignación de modelos por criticidad. Perfecto para aprender LangGraph.

🚀

Acelerar el flujo de PR

Genera el título en formato conventional commits, la descripción del PR, la entrada de CHANGELOG y un checklist de QA para el revisor humano. El "papeleo" del release, hecho.

📦

Higiene de dependencias

Lista las librerías usadas, sugiere versiones pinneadas seguras, marca CVEs conocidos y licencias incompatibles, y arma el requirements.txt.

Cómo usar el equipo en Claude Code

La Compañía no vive solo como programa Python: también habita dentro de Claude Code como agentes nativos, listos para convocar.

✦ Gratis con tu plan mensual · sin API key ✦

⚙️ Dónde viven

  • Cada agente es un archivo en .claude/agents/ (Gandalf, Samwise, Elrond…).
  • Corren bajo tu suscripción, sin pago por token.
  • Trabajan sobre tu repositorio real: leen, editan archivos y corren tests de verdad.

🗣️ Cómo convocarlos

Por su nombre, o pidiéndolo en lenguaje natural:

Elrond, revisá src/team.py Aragorn, audita la seguridad del login Gandalf + Samwise + Legolas: creá un validador de CUIT con tests

La diferencia con el proyecto Python es clave: aquel genera un módulo aislado y cobra por la API; esta versión trabaja sobre tu código real, gratis, dentro de tu plan. Misma hermandad, mismos roles, mismos modelos (Opus / Sonnet / Haiku) — pero a tu lado mientras programás.
